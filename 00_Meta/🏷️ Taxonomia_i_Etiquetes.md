# 🏷️ Guia de Taxonomia i Sistema d'Etiquetes

Per mantenir l'ordre i potenciar les cerques a Obsidian i les taules Dataview, s'utilitza aquest sistema jeràrquic d'etiquetes:

---

## 📂 Etiquetes Estructurals
* `#docencia/sessio`: Identifica les notes de preparació i diari de classe a `02_Sessions/`.
* `#docencia/exercici`: Identifica les pràctiques i laboratoris a `03_Exercicis_i_Labs/`.
* `#docencia/teoria`: Identifica els apunts i documents tècnics a `01_Temari/`.
* `#docencia/projecte`: Identifica la documentació del projecte transversal a `04_Projecte_Videojocs/`.
* `#docencia/moc`: Identifica els índexs i mapes de continguts.

## 🎯 Resultats d'Aprenentatge (RAs)
* `#ra/ra1`: Proves d'aplicacions web i mòbils (Desenvolupament bàsic).
* `#ra/ra2`: Determinació del nivell de seguretat i identificació de vectors d'atac.
* `#ra/ra3`: Detecció i correcció de vulnerabilitats web.
* `#ra/ra4`: Seguretat en aplicacions mòbils.
* `#ra/ra5`: Desplegament segur i DevSecOps.

## 🛡️ Vulnerabilitats i Seguretat
* `#vulnerabilitat/sqli`: Injeccions SQL.
* `#vulnerabilitat/xss`: Cross-Site Scripting.
* `#vulnerabilitat/auth`: Autenticació i sessions trencades.
* `#vulnerabilitat/idor`: Insecure Direct Object References.
* `#vulnerabilitat/lfi`: Local File Inclusion.
* `#vulnerabilitat/rfi`: Remote File Inclusion.
* `#vulnerabilitat/upload`: Pujada de fitxers insegura.
* `#vulnerabilitat/rce`: Remote Code Execution.

## ⚙️ Eines i Tecnologies
* `#eina/burp`: Burp Suite.
* `#eina/docker`: Docker i Docker Compose.
* `#eina/sqlmap`: SQLmap.
* `#eina/frida`: Frida i Objection.
* `#eina/mobsf`: Mobile Security Framework.
* `#stack/php`: PHP 8.x.
* `#stack/mysql`: MySQL / MariaDB.
* `#stack/js`: JavaScript ES6+.
